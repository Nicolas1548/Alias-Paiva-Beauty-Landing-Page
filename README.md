## 📖 Sobre o projeto

Landing page de uma página só, criada para a marca **Alias Paiva Beauty**. O objetivo é simples: mostrar o trabalho, passar confiança e levar a cliente direto ao WhatsApp, com a mensagem de agendamento já preenchida.

A identidade visual segue a marca: **lilás e dourado**, tom delicado e acolhedor, com o mesmo cuidado que a Alias tem em cada atendimento.

## 🛠️ Sobre o desenvolvimento

- **Tipo:** site estático, responsivo (mobile first)
- **Tecnologias:** HTML, CSS e JavaScript
- **Entrega:** página autocontida em um único `index.html`, com pasta `images/` para as fotos
- **Conversão:** todos os botões levam ao WhatsApp, com mensagens diferentes para agendamento e para o Curso VIP
- **SEO:** `title` e `description` focados em busca local, URL canônica, Open Graph (1200×630) e Twitter Card para boa pré-visualização ao compartilhar
- **Acessibilidade:** textos alternativos descritivos em todas as imagens da galeria

### Estrutura

```
.
├── index.html
├── images/
│   ├── og-image.jpg   # imagem de compartilhamento
│   ├── hero.jpg
│   ├── about.jpg
│   └── gallery*.jpg
└── README.md
```

### Rodando localmente

```bash
python -m http.server 8000
# ou
npx serve .
```

Acesse `http://localhost:8000`.

### Atualizando o conteúdo

- **Galeria:** coloque a foto em `images/`, adicione o item na seção Galeria e escreva um `alt` descritivo.
- **WhatsApp:** edite o parâmetro `text` (codificado em URL) nos links `api.whatsapp.com/send`.
- **Compartilhamento:** troque `images/og-image.jpg`, mantendo 1200×630 px.
